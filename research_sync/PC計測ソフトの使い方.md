# PC操作のQuest・ComBalance計測ソフト

現在の操作手順はこちらを優先する。解析は実行せず、収録とCSV保存を行う。

## 起動と操作

1. QuestとComBalanceをUSBでPCへ接続する。メーカーのComBalanceソフトは同時に機器を開かない。
2. `計測ソフトを起動.cmd` をダブルクリックする。PCアプリがUSB転送と計測サーバーを準備する。
3. 初回はQuest Browserで `http://localhost:8443` を開き、標準のVRボタンでVRへ入る。
   ブラウザの仕様上、この最初のVR開始だけはQuest側の操作が必要。
4. PCアプリで開始までの待ち時間を指定し、「90秒試行を予約」を押す。既定は10秒、範囲は3～30秒。
5. ComBalanceの取得開始を確認した後、指定秒数のカウントダウンに入る。その間にQuestを装着し、決めた位置・向きに合わせる。
6. 予約したPC時刻にQuestが自身の時計で再生する。未装着・描画停止・時刻対応未準備のまま予約時刻を過ぎた場合は中止し、遅れて自動開始しない。
7. 自然終了、またはPCの「停止」で収録を終了する。機器設定を復元し、CSVを自動保存する。
8. 「保存先を開く」で試行フォルダを開く。接続中の保存場所は固定。
9. アプリを閉じるときは停止・保存を待つ。機器設定復元を省略する強制終了は使わない。

試行の開始停止にコントローラーは不要。計測映像に操作メニューやレーザーを表示しない。
Questを外して描画が止まった場合は試行を中断する。再接続しても古い開始を自動再生しない。
ブラウザやOSがVRセッションを終了した場合は、再度Questの標準VRボタンで入る必要がある。
USB抜線後は「USB接続を再確認」で転送を復旧できる。

## 映像条件

ユーザー確認済みの90秒・30周波数同時マルチコサインを維持。
0.05～1.50 Hz、0.05 Hz刻み、定常部の各加速度成分振幅は共通。
合成最大速度0.10 m/s。既存の位相・5秒の始終端ランプ・波形数式は変更していない。

`scene.json` の寸法を表示に反映する。

```json
{
  "roomHeightM": 3,
  "roomSizeM": 6,
  "frontWallDistanceM": 3,
  "gridSpacingM": 0.5
}
```

6×6 m・高さ3 mの格子部屋を前後並進する。頭部を刺激として動かす処理ではない。
壁は横12マス×縦6マス、床・天井は12×12マスなので格子間隔は50 cm。
正面壁までの3 mは固定したVR床原点を基準とする。被験者は決めた位置・向きに合わせる。
リセンタリングで原点が変わった場合は、実空間との対応を確認する。
A-Frame 1.7.0と格子画像をPCからUSB経由で配信するため、表示のための外部CDN通信は不要。

## PC操作と遅延

PCが毎フレームの位置を送る方式ではなく、少し先の開始時刻を予約し、Questがローカル再生する。
そのためPCの操作通信にかかった時間が、そのまま刺激の開始ずれとして加算される方式ではない。
Quest時計とPC時計は継続的な4時刻プローブで対応づける。予約に間に合わない指令は再生しない。
有線接続はADB USB転送を使う。USBデバッグの許可は最初にユーザーが行う。

ComBalanceはメーカーAPIで取得し、PC共通時計で開始指令と各受信ブロック前後の時刻を保存する。
センサの真の取得時刻と、PCへの受信時刻は区別する。
センサ取得遅延およびQuest実発光遅延は独立校正されていないので、絶対同期精度を保証しない。

## 保存されるファイル

既定の親フォルダは、このディレクトリの `recordings/`。
起動ごとに新規セッションを作り、各試行の `trials/試行ID/` に以下を保存する。

| ファイル | 内容 |
|---|---|
| quest.csv | 試行ID、Quest時刻、PC対応時刻、刺激経過秒、AP変位・速度・加速度、適用状態 |
| combalance.csv | 試行ID、サンプル番号・経過秒・周波数、PCブロック受信前後時刻、暫定サンプル時刻、床反力6軸、元ADC、IMUカウント |
| clock_probes.csv | Quest送信、PC受信、PC送信、Quest受信の4時刻 |
| metadata.json | 刺激条件、PC指令時刻、時計補正・ドリフト、機器設定、CSVの品質と時刻の意味 |
| combalance_raw/raw_blocks.jsonl | メーカーAPIで受信したバイト列と読出し時刻。元記録として保存 |
| combalance_raw/device_parameters.json | 読み出したメーカー校正係数・設定・サンプリング条件 |
| combalance_raw/helper_shutdown.txt | 取得停止・設定復元の結果 |

床反力列は `sensor_Fx_N`、`sensor_Fy_N`、`sensor_Fz_N`、`sensor_Mx_Nm`、`sensor_My_Nm`、`sensor_Mz_Nm`。
センサ座標のまま保存し、被験者AP方向へ勝手に再割当てしない。
校正係数による工学単位への換算は行うが、HPF・LPF・COM推定・FRF処理は行わない。

`pc_estimated_sample_time_s` は受信時刻からの暫定的な時計再構成。
`timestamp_quality=receipt_fit_unvalidated` と明記し、未検証の `pc_acquisition_time_s` は空欄にする。
後で位相を解析する場合は取得・表示遅延の校正が必要。相対サンプル時刻と生受信時刻は全て残す。

途中停止でも取得済みCSVを保存する。刺激開始前のキャンセルではQuest CSVはヘッダーのみになる。
既存の生データを上書きしない。試行中に別の解析ソフトを起動する必要はない。

## 実施した確認

- PC画面の起動・USB接続・時計通信・更新状態の表示。
- PC予約、実ComBalance取得、刺激開始前の停止、CSV自動保存、元の転送設定への復元。
- 模擬XRで、予約中の装着、予約時刻での開始、期限超過の中止、描画停止時の中断。
- 壁12×6、床12×12の設定と50 cm間隔。
- CSVの元サンプル保持、取得時刻未校正の明示、上書き拒否。

前版では空荷・立位の90秒同時取得も確認済み。
今回のPC操作版ではその波形を維持し、操作と自動CSV保存を追加した。人での追加90秒試行を勝手に開始していない。
