## 目線高さの手動取得（更新）

PCアプリを再起動し、Questの8443ページを再読み込みしてください。被験者が決めた位置でQuestを装着しVR表示に入ったら、PCの「目線高さを取得し直す」を押します。取得済みの高さがメートル単位で表示されます。これはlocal-floor床基準のHMD視点高さで、眼球追跡による注視方向の計測ではありません。

必要なら姿勢・立ち位置を直して再度押し、その後に試行を予約します。高さの取得操作は立ち位置が正しいかを判定しません。立ち位置は実験者が確認します。赤点とローディング表示は取得した高さに固定されます。条件切替による自動再取得は行いません。予約中・試行中・保存中の変更は禁止しています。赤点・ローディング条件は未取得のまま開始できません。VR退出・切断後には再取得してください。

高さ取得イベントとQuest時刻はセッションログに、試行開始時の高さと取得時刻は各試行のmetadata.json内stimulusに保存します。各描画フレームの注視点座標もquest.csvに残ります。

# 床反力と同期して使う場合（追加）

既存の「VR × ComBalance 計測」アプリを再起動し、Questの http://localhost:8443 も再読み込みしてください。アプリ上部に90秒マルチコサインと30秒の3条件を選ぶ欄を追加しました。「USB接続・準備」の後に条件を選び、試行を予約します。予約待ち時間は既存の設定（通常10秒）です。取得準備に時間がかかる場合は、準備完了後から待ち時間を数えます。

床反力取得は予約カウントダウン前の準備段階で開始し、刺激終了後に停止・保存します。刺激の開始・終了は試行IDとイベントで区別できます。30秒条件は自動終了します。試行中は条件変更できません。次の条件はCSV保存完了後に選んでください。

- `quest.csv`: 刺激時刻・PC対応時刻・変位・速度・加速度に加え、`visual_condition`（none/dot/spinner/multicosine）と固定対象のXYZ座標を保存。
- `combalance.csv`: 元の床反力・モーメントと時刻。Questと同一の試行IDです。
- `clock_probes.csv`: QuestとPCの時計対応に使う往復通信。
- `metadata.json`: その試行で選んだ刺激設定を保存（セッション冒頭の設定とは区別）。

元の90秒試行と同じ時計対応・取得経路です。床反力の絶対取得遅延とQuestの実表示遅延は未校正であり、物理的なミリ秒精度の同時性を保証するものではありません。COM/FRF解析は実行しません。今回のソフトウェア試験は実機の同期精度検証を代替しません。

以下の8872版は映像だけを確認する独立プレビューです。**床反力と同期する試行には、既存計測アプリと8443側を使ってください。**

# 注視条件比較用・30秒映像

元の90秒アプリとは別の映像専用ツールです。ComBalance取得・同期・解析や標準刺激設定は変更しません。

## 使い方

1. QuestをUSB接続して `start_fixation.cmd` をダブルクリックします。USBデバッグ許可済みのQuestが1台接続されていることが前提です。
2. PCで http://localhost:8872 を開きます。
3. Quest Browserで http://localhost:8872/q を開き、VRに入ります。
4. PCで「注視点なし」「空間固定の赤い点」「空間固定のローディング表示」を選びます。
5. 「3秒後に30秒再生」を押します。30秒で自動終了して原点に戻ります。途中の停止ボタンは即座に原点へ戻します。

PCプレビューのみなら `python -m research_sync.fixation_server` でも起動できます。既にサーバーが起動している場合は、再起動せずPC画面を開いてください。サーバーを止めるときは起動したコンソールでCtrl+Cを押します。

## 共通条件

- 30秒、単一周波数0.20 Hz、最大絶対速度0.10 m/s。
- 灰色、格子50 cm、部屋6×6×3 m、正面壁まで3 m。
- 初めと終わりの3秒は5次包絡による滑らかな接続。3～27秒が純粋な単一周波数です。接続区間には包絡による他周波数成分が含まれます。
- 基本変位は `x(t)=B (cos(2πft)−1)`、包絡を掛けて速度・加速度を解析的に微分。全区間の速度ピークで共通スケールを決めます。30秒で位置・速度・加速度がゼロになります。
- 赤点: 直径5 cm、距離2.5 m。回転表示: 外径約15.4 cm、毎秒1回転。
- 注視対象は動く部屋ともカメラとも別のlocal-floor空間座標に置きます。VRに入った後の目の高さを一度だけ採用し、以後は固定します。試行中に再センタリングしないでください。

`fixation.js` 冒頭の `config` で周波数・時間・最大速度・対象距離などを変更できます。変更後はPCとQuestページを再読み込みします。

回転表示は注意を引く操作であり、注視を保証しません。また赤点より大きく回転するので、結果は「この3種類の表示条件の差」として扱えます。実際の注視を確定する機能や身体動揺の記録機能はありません。

PCからQuestへの開始は100 ms間隔の状態取得と時計差推定を用います。このツールは映像比較用で、外部計測との精密な開始同期を保証するものではありません。
